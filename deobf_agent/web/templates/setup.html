Sayt hali yopilmagan: kirish kodi qo'yilmagan.

Serverda sizning Claude kalitingiz (ANTHROPIC_API_KEY) bor, lekin DEOBF_ACCESS_CODE yo'q. Kodsiz sayt hammaga ochiq bo'lardi, shuning uchun u to'xtatib qo'yildi va kalit ishlatilmayapti.

Nima qilish kerak (1 daqiqa):

  1. Render → servisingiz → Environment → Add Environment Variable.
  2. Nomi: DEOBF_ACCESS_CODE (aynan shunday), qiymati: o'zingiz tanlagan kod.
  3. Save Changes. Render servisni o'zi qayta ishga tushiradi (1–2 daqiqa), keyin sahifani yangilang.

Shundan keyin sayt kodni so'raydi, kirgach esa Claude kalitingiz bilan ishlaydi va hech narsa kiritmaysiz. Saytni hammaga ochiq qilmoqchi bo'lsangiz, ANTHROPIC_API_KEY ni Render'dan o'chiring.
